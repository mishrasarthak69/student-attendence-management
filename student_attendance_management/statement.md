# Project Statement – Student Attendance Management System

## Problem Statement
Manual attendance records can be difficult to maintain, search, and summarize. This project provides a simple command-line system to store student information and record daily attendance.

## Scope
The project supports adding students, viewing and searching students, marking Present/Absent attendance, viewing attendance records, and generating a simple attendance report.

## Storage
All data is stored locally in `data/students.txt` and `data/attendance.txt`.

## Excluded
No GUI, web server, online database, cloud storage, login system, biometric attendance, or external API is used.

## High-Level Features
- Add Student
- View Students
- Search Student
- Mark Attendance
- View Attendance
- Attendance Report
- Local text-file storage
